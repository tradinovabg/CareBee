# CareBee — голосовой дневник ухода и самочувствия

Одна мобильная веб-страница на существующем стеке Next.js 16 / React 19 / TypeScript. Данные дневника хранятся **только в localStorage браузера текущего устройства**, ключ `carebee.diary.v1`. Регистрации, общего доступа, календаря, задач и медицинских рекомендаций нет. Есть локальные профили получателей и переход в WhatsApp с подготовленным текстом.

## Запуск

Используемая версия Node.js: 24.

```sh
cd /workspace/CareBee
npm ci
npm run build
npm start
```

Приложение слушает порт 3000. Для разработки: `npm run dev`. Живые процессы после восстановления облачного окружения нужно запускать заново. Используйте существующий checkout; отдельный Git worktree не нужен.

## Как открыть на телефоне

Текущий локальный сервер в облаке не является публичной ссылкой. `localhost` на телефоне означает сам телефон, а не эту облачную машину.

Для семейного тестирования следующий шаг — разместить проект на доступном семье **HTTPS-хостинге с поддержкой Next.js** и открыть выданный хостингом адрес. Например, можно подключить репозиторий к Vercel и проверить условия бесплатного тарифа до публикации. Платные услуги не подключены. Для обычного Node-хостинга: команда сборки `npm ci && npm run build`, запуск `npm start`, порт 3000 за HTTPS reverse proxy. Серверная база и API-ключи не нужны. Не используйте один общий демонстрационный браузер для личных записей.

На компьютере разработки loopback-адрес считается безопасным контекстом; на телефоне обычный HTTP по IP-адресу не подходит для надёжной работы микрофона. Нужен доверенный HTTPS-сертификат. При открытии внутри другого приложения лучше перейти в полноценный браузер.

### Первая запись

1. Откройте HTTPS-адрес в Chrome на Android или Safari на iPhone; поддержка распознавания зависит от версии браузера и настроек устройства.
2. Для первой проверки используйте вымышленные сведения.
3. Прочитайте уведомление о передаче голоса сервису браузера. Нажмите «Записать голосом», разрешите микрофон и дождитесь «Слушаю».
4. Продиктуйте сообщение и нажмите «Остановить». Проверьте текст, исправьте ошибки и нажмите «Сохранить».
5. Если микрофон запрещён: разрешите его в настройках сайта браузера и в разрешениях браузера в ОС. Если распознавание недоступно — вводите текст вручную.
6. Обновите страницу: запись должна остаться. «Скачать .txt» выгружает только сохранённые записи; на iPhone браузер может предложить меню сохранения/открытия файла.

## Голос и конфиденциальность

Используется настоящий Web Speech API: `SpeechRecognition` / `webkitSpeechRecognition`, язык `ru-RU`. Распознанный текст можно исправить. Начало и остановка вызывают реальные `start()` / `stop()`. Нет имитации, подставных транскриптов или платного сервиса CareBee.

Поддержка API и русского языка зависит от браузера/устройства. По актуальной документации MDN распознавание обычно использует серверный сервис поставщика браузера: например, Google в Chrome или Apple в Safari. Аудио может покидать телефон; конкретная обработка определяется браузером и его настройками. Обычно нужен интернет. Приложение предупреждает об этом **до запуска** и позволяет не использовать голос. Экспериментальное локальное распознавание `processLocally` не включено: наличие подходящего русского языкового пакета на телефоне не гарантируется.

CareBee не записывает аудиофайлы, не отправляет содержание дневника на свой сервер и не хранит ключи. Старый `/api/state` отключён (ответ 410), прежняя SQLite-база не используется дневником. Старые демонстрационные файлы базы при обновлении не удаляются автоматически.

До нажатия «Сохранить» текст существует только в памяти страницы. Черновик не сохраняется автоматически. Отказ или переполнение localStorage не очищает поле. Обновление/закрытие страницы может потерять черновик; браузеру передаётся стандартное предупреждение о несохранённых изменениях, но мобильные браузеры не всегда показывают его.

Данные между телефонами и браузерами **не синхронизируются**, при очистке данных сайта могут исчезнуть; в приватном режиме хранение может быть временным. Экспортируйте резервную копию. Файл экспорта содержит личный текст без шифрования. Даты отображаются в часовом поясе устройства; редактирование сохраняет первоначальную дату создания.

## Проверки

```sh
npm test
npm run typecheck
npm run build
```

Проверки дневника: явное сохранение, повторное чтение, порядок записей, редактирование с сохранением даты, удаление, текстовый экспорт, повреждённые/недоступные данные, защита от перезаписи устаревшей записью из другой вкладки. localStorage не даёт транзакций между одновременно записывающими вкладками; для теста используйте одну вкладку на устройстве.

В реальном headless Chromium с вымышленными данными проверены: отсутствие сохранения до подтверждения, сохранение после перезагрузки, редактирование и повторная перезагрузка, отмена/подтверждение удаления, скачивание и содержимое `.txt`, отказ микрофона и последующий ручной ввод, ширина страницы 390 px без горизонтальной прокрутки.

**Успешное распознавание живой русской речи не проверено:** в облачном тестовом окружении нет человеческого микрофона. Требуется проверка реальным телефоном по HTTPS. Наличие API не доказывает, что сервис распознавания доступен на конкретном устройстве.

## Получатели и WhatsApp

- Экран `/recipients`: имя, алиасы через запятую/новую строку, международный номер, канал WhatsApp, отметка «Основной». Профили хранятся в `carebee.recipients.v1` в localStorage. Номера не загружаются на сервер CareBee. При переходе в WhatsApp номер и текст передаются WhatsApp.
- В схеме канал — отдельное строковое поле и реестр `CHANNELS` в `lib/recipients.mjs`. Сейчас доступен только WhatsApp; будущие каналы потребуют собственного обработчика ссылки и записи в реестре.
- После завершения диктовки имена/алиасы сравниваются только по краям фразы. Регистр, `ё/е`, пунктуация и распространённые русские окончания учитываются. Это консервативная эвристика, а не полноценный морфологический анализ: для нерегулярных имён добавляйте алиасы. Похожие/неоднозначные обращения не удаляются и требуют ручного выбора. Текст внутри фразы не меняется. Автоматической пунктуации нет.
- «Сохранить» по-прежнему сохраняет только запись, без открытия мессенджера. «Отправить» показывает имя, номер и текст, затем отсчитывает 5 секунд. До окончания отсчёта нет сохранения и перехода. «Отмена», Escape или сворачивание страницы останавливают отсчёт, сохраняя черновик в поле.
- После отсчёта сначала сохраняется запись с отметкой, затем открывается `https://wa.me/<цифры>?text=<encodeURIComponent(text)>` в текущей вкладке. Так не требуется открывать всплывающее окно из таймера. Если автоматический переход не сработал, остаётся явная ссылка «Перейти в WhatsApp»; повторного сохранения при этом нет.
- Последнее подтверждение отправки пользователь делает **в самом WhatsApp**. Приложение не получает подтверждения отправки или доставки. Строка «Отправлено: имя · время» в дневнике и экспорте означает передачу подготовленного сообщения в WhatsApp и содержит это пояснение. Это не квитанция о доставке. Изменение текста записи позже не меняет уже открытое сообщение в мессенджере. Старые отметки сохраняют имя на момент перехода даже после удаления профиля.
- Перед переходом профиль повторно читается из хранилища: изменение номера/имени или удаление в другой вкладке отменяет переход и требует нового подтверждения. Ошибка сохранения блокирует переход.
- На телефоне: «Получатели» → добавить профиль с номером → отметить основной при необходимости → вернуться в дневник → сказать «Маме, сегодня всё хорошо» или выбрать человека кнопкой → проверить текст → «Отправить» → проверить имя за 5 секунд → подтвердить отправку в WhatsApp. Сначала используйте вымышленный текст и проверенный собственный номер.

Публикация настроена пользователем в Vercel для проекта `care-bee` из ветки `main` репозитория `tradinovabg/CareBee`. Дальнейшие обновления отправляются через Git; Vercel CLI не требуется.

Проверка обновления получателей: 15 автоматических тестов (включая прежние проверки), production-сборка и браузерный сценарий Chromium на ширине 390 px. Проверены добавление/изменение/основной профиль/удаление с отменой и перезагрузкой, отмена отсчёта без сохранения, реальный пятисекундный таймер, точная `wa.me`-ссылка, одна сохранённая отметка и её экспорт, сохранение без получателя. Внешняя навигация WhatsApp перехватывалась тестом: сообщений не отправлялось. Для проверки соединения распознанного текста с выбором адресата использовалось искусственное событие распознавания только в тестовом браузере; живая речь и приложение WhatsApp на телефоне требуют ручной проверки.
